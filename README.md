## Overview

Simple Sidearms allows RimWorld colonists to carry backup weapons in addition to their primary, switching between them based on combat range or manually. Melee fighters can carry a ranged backup for approaching, ranged fighters can carry a melee weapon for when enemies close distance, and loadout configurations can be saved as presets.

Whether you're a newcomer just getting started or a seasoned pro looking for advanced tools, **RimWorld Simple Sidearms** delivers the features you need in a clean, intuitive package.

## Key Features

| Feature | Description |
|---------|-------------|
| **Multi-Weapon Carry** | Each colonist carries a primary and configurable number of sidearms |
| **Auto Weapon Switch** | Pawns auto-switch to melee when enemies enter close combat range |
| **Loadout Presets** | Save and apply weapon loadout configurations across colonists |
| **Memory System** | Pawns remember their last equipped weapon after interactions |
